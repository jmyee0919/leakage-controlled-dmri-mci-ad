Data file S1. Aggregate numerical results (CSV) underlying Tables 1-4 and S1-S28 of the manuscript and Supplementary Materials (second revision).
File names give the table number in the current Supplementary Materials; files from earlier versions were renamed to the current numbering.
Files named Table_2_3_* contain the four-model holdout metrics, paired differences and repeated cross-validation summaries for Tables 2 and 3 (imaging and five-covariate models).
Analysis labels such as broader_QC are code identifiers; 'QC' in these labels refers to the post hoc numerical plausibility rules, not segmentation quality control.
No participant-level data are included; ADNI participant-level data are available from adni.loni.usc.edu under the ADNI Data Use Agreement.
