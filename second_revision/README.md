# Second revision version 3.0.0

`Data_file_S1/` contains the 50 submitted aggregate CSVs plus the new training-versus-holdout comparison (Table S28B). The source submission package contained aggregate outputs, not the executable second-revision implementation. `code/reproduce_revision2.py` is a new final-verification implementation of the documented frozen models. Its holdout metrics and all per-repeat AUCs reproduce the supplied exports within their six-decimal rounding precision. It does not claim to recover unavailable author code or to prove prospective prespecification.

## Files

- `code/reproduce_revision2.py`: all four models, imaging and five-covariate primary analyses and imaging broader cohort; conditional 500-draw bootstrap, full 3-fold × 10-repeat refitting, independently implemented predictions, and checks against the submitted exports.
- `models/four_model_parameters.csv` and `four_model_preprocessing.csv`: coefficients, intercepts, sigmoid parameters, imputation values and scaling moments for all 12 holdout arms, separated by inner fold. Repeated-validation fits are generated by the code rather than redistributed as opaque models.
- `verification/`: aggregate rerun results, per-repeat AUCs and a machine-readable verification record. No individual predictions are included.
- `code/partition_characteristics.py`: Table S28B from the frozen primary cohort, with no fitting or change to the partition.
- `code/render_second_revision.py`: analytical recreation of Figure 3 and (with restricted primary input) Figure S1. The recreation preserves data and interpretation; the archived submitted PDFs preserve the exact publication layout.
- `code/update_figure1.py` and `figure_source/Figure_1_before_label_clarification.pdf`: deterministic vector-label clarification to last-known recorded MCI, retaining the rest of the original diagram.
- `figures/`: all seven final publication PDFs. Existing supplementary calibration, clinical ROC/PR and synthetic plots can also be recreated with `scripts/render_figures.py`; their second-revision numbering is S2, S3 and S4 respectively.

## Authorized input contract

Use CSV files derived from the frozen, already validated cohorts; retain their original row order. Neither file is included publicly. Each must contain unique `participant_key`, `split` (`train`/`test`), binary `y`, `hippo_base`, `entorh_base`, `vent_base`, `hippo_follow`, `entorh_follow`, `vent_follow`, and each regional `*_relchange_emp` and `*_relchange_emp_isna`. The primary file additionally contains `age`, `female`, `education`, `MMSE`, `ICV` (mm³), and `interval_months`. Missing MMSE values remain missing. Changes are annualized fractions, not percentages; the retained availability flags are all zero. Primary counts are 106/35 events, training 76/26, holdout 30/9. Broader counts are 106/28, training 73/19, holdout 33/9. The cohorts overlap and are not independent replications.

```bash
python second_revision/code/reproduce_revision2.py --primary /authorized/primary.csv --broader /authorized/broader_QC.csv --out /private/revision2_rerun
python second_revision/code/partition_characteristics.py --primary /authorized/primary.csv --out /private/Table_S28B.csv
python second_revision/code/render_second_revision.py --primary /authorized/primary.csv --out /private/revision2_plots
```

Keep all clinical rerun outputs outside the public repository: the script writes private participant predictions as well as aggregate results. It never silently changes a cohort, split, predictor or threshold to obtain a match. Rounded CSV references are compared with absolute tolerance 5.1 × 10⁻7. Two independently implemented prediction pipelines agreed within 5.1 × 10⁻14 across holdout and repeated cross-validation; the exact observed maximum is in `verification/REPRODUCTION_REPORT.json`.

These checks start from frozen derived tables. They do not repeat raw ADNI extraction, diagnose the six early AD cases, validate segmentations, regenerate the unavailable synthetic generator or establish external clinical validity. Full descriptive acquisition/ascertainment source-to-table reconstruction is not included; their reported aggregate tables are supplied and consistency checked.
