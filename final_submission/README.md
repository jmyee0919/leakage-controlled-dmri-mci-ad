# Final submission files (v2.0.1)

This folder matches the files submitted with the revised manuscript "Short-Interval MRI Volume Change and 24-Month Progression From MCI to Alzheimer's Disease".

- `Data_file_S1/`: Data file S1 exactly as submitted. File names use the final Supplementary Table numbers.
- `figures/`: final Figures 1–3 and S1–S3 as submitted.

The files in `data/aggregate/` and `figures/` at the top level of this repository use the numbering of the earlier revision draft (v2.0.0) and are kept unchanged so that `scripts/verify_public_release.py` and earlier commits remain valid.
