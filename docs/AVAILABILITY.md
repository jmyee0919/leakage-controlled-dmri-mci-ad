# Availability statements

## Data availability

Aggregate tables, analysis specifications and figure-level numerical inputs are available in the Supplementary Material, Supplementary Data 1 and the study repository (https://github.com/jmyee0919/leakage-controlled-dmri-mci-ad). Participant-level imaging and clinical data are available to approved researchers through the ADNI/LONI Image and Data Archive (https://adni.loni.usc.edu/data-samples/adni-data/) under the ADNI Data Use Agreement. The authors do not redistribute raw or derived participant-level ADNI data.

## Code availability

Code and fitted-model parameter exports for this revision are available at https://github.com/jmyee0919/leakage-controlled-dmri-mci-ad (version 2.0.0, 23 October 2026). The repository contains QC and model specifications, scripts for reproduction from frozen derived inputs, independent numerical checks, figure-rendering code and dependency versions. Re-running clinical analyses requires authorized participant-level inputs described in the repository. The revised synthetic specification and archived summary outputs are included; the complete executable synthetic generator and full historical raw-to-cohort workflow were unavailable.

The manuscript should cite the immutable Git commit identifying this revision. No DOI is assigned or implied by this GitHub release.
