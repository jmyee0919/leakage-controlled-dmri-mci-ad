# Data access

Participant-level imaging and clinical data were obtained from the Alzheimer's Disease Neuroimaging Initiative. ADNI distributes data through the LONI Image and Data Archive to approved researchers under its Data Use Agreement and publication policies.

Apply through the [official ADNI data access page](https://adni.loni.usc.edu/data-samples/adni-data/). The authors do not redistribute raw or derived participant-level ADNI datasets. The repository's software license does not override ADNI access conditions.

The public data folders contain summary tables from Supplementary Data 1, plotted curve coordinates, repeat-level aggregate metrics, fitted model parameters, and synthetic specifications/saved summaries. Patient-specific diagnoses, visit histories, scan/image IDs, linkage records and individual predictions are excluded.

Re-running clinical fits requires authorized frozen derived inputs described in `REPRODUCIBILITY.md`; those inputs are not bundled. The complete revised synthetic generator is not included. The public renderer runs without access to any restricted inputs.
